## Projects
 
### Multi-Agent Systems
 
- 🏭 **[IndusGuard](https://github.com/rupali-chauksey/indusguard)** - Agentic AI for industrial intelligence: predictive maintenance, anomaly detection and mitigation planning.
  - Diagnostic, Predictive and Planning agents working together
  - Isolation Forest anomaly detection on multivariate telemetry, gradient-boosted RUL forecasting
  - Spatial 3D digital twin, RAG for maintenance context
  - Human-in-the-loop approvals with role-based access (operator / supervisor / plant head)
  - `Python` `Streamlit` `Groq` `ChromaDB` `scikit-learn` `Plotly` `NetworkX` `SQLite` `Docker`
- 🛒 **[OptiVendor](https://github.com/rupali-chauksey/OptiVendor)** - Autonomous multi-agent procurement: checks stock, negotiates with vendors, places orders, and asks a manager when an order is too expensive.
  - LangGraph state machine with 5 specialized agents
  - Guardrails (budget, overstocking, loop) enforced in Python code, not in prompts
  - Manager approval for orders above $500, agent-to-agent price negotiation
  - Every decision logged to `approval_log.txt`
  - `Python` `LangGraph` `Ollama` `SQLite` `Streamlit` `Pandas`
### RAG & Knowledge

  - Grounded, citation-aware answers to cut down hallucination

  - `Python` `RAG` `MCP` `LangChain` `Vector DB`
